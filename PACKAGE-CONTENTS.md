# Conteúdo do pacote

- `src/`: aplicação React funcional de demonstração.
- `src/assets/logo-elos-dark.svg`: cópia exata do SVG fornecido na conversa.
- `public/logo-elos-dark.svg`: ativo público utilizado pela interface.
- `docs/desafio-areco-apresentacao-rascunho.pdf`: capa + 3 slides de conteúdo + encerramento; revisar e personalizar antes de enviar.
- `docs/figma-handoff.md`: roteiro para construir o arquivo e o protótipo na conta Figma.
- `docs/product-decisions.md`: briefing, público, proposta de valor, arquitetura conceitual, escopo e riscos.
- `docs/design-tokens.json`: tokens iniciais.
- `README.md`: instalação, execução, build e deploy.

O logo foi copiado sem alteração. A identidade visual, cores e dados são propostas conceituais; não representam um brandbook oficial nem dados reais da Areco.
